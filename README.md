# 経営指標診断ツール

決算データ（または決算前企業向けの月次試算表データ）をもとに主要な経営指標を自動計算し、中小企業庁の統計データと比較して診断するWebアプリです。複数のクライアント企業のデータをアカウントごとに管理できます。

将来的なサービス化を見据え、フロントエンド（素のHTML/CSS/JS）＋バックエンドAPI（Node.js/Express）＋DB（SQLite）の構成にしています。

## 主な機能

- メール／パスワードでのアカウント登録・ログイン（会社データはユーザーごとに分離）
- クライアント企業の登録・業種選択・一覧管理
- 決算データ（年次）または月次試算表データ（決算前企業向け・自動で年換算）の入力
- CSVによる一括インポート
- 自己資本比率・売上高経常利益率・総資本回転率・簡易ROE・流動比率・売上高付加価値率・労働生産性の自動計算
- 中小企業庁の統計データ（業種別）との比較・良好/平均的/要注意の自動診断
- 指標の推移グラフ、業種平均との比較グラフ

## セットアップ

Node.js 22.5 以降が必要です（`node:sqlite` を使用しているため）。`node -v` で確認してください。

```bash
npm install
npm start
```

`http://localhost:3000` を開くとアプリが使えます。初回起動時に `data/app.sqlite` が自動作成されます。

開発中はファイル変更を自動反映する `npm run dev` が便利です。

### テスト

計算ロジックのユニットテストがあります。

```bash
npm test
```

## 使い方

1. アカウントを作成してログイン
2. 「クライアント企業を追加」で会社名・業種を登録
3. 会社をクリックして詳細画面へ。決算データを1件ずつ入力するか、CSVで一括インポート
4. 決算前でまだ1年分のデータがない会社は、「月次試算表（決算前・年換算して簡易診断）」を選び、経過月数を入力すると自動で年換算して簡易診断できる
5. データが1件以上あれば、推移グラフと診断結果が自動表示される

## CSVフォーマット

1行目はヘッダー、1行=1期間分のデータ。金額の単位はすべて「円」。

| 列名 | 内容 |
|---|---|
| 年度 | 期間のラベル。例: 2024年3月期 |
| 経過月数 | 省略可。1〜11を入れると「決算前の月次試算表」として年換算される。空欄または12以上なら決算実績として扱う |
| 売上高 | 円 |
| 経常利益 | 円 |
| 総資産 | 円 |
| 純資産 | 円 |
| 流動資産 | 円 |
| 流動負債 | 円 |
| 従業員数 | 人 |
| 付加価値額 | 円（不明な場合は空欄可。労働生産性・付加価値率の診断のみスキップされる） |

サンプル: `data/sample_annual.csv`（決算実績・3期分）、`data/sample_monthly.csv`（決算前・月次試算表）

## 算出している指標

| 指標 | 計算式 | 観点 |
|---|---|---|
| 自己資本比率 | 純資産 ÷ 総資産 × 100 | 安全性 |
| 売上高経常利益率 | 経常利益 ÷ 売上高 × 100 | 収益性 |
| 総資本回転率 | 売上高 ÷ 総資産 | 効率性 |
| 自己資本当期純利益率（簡易ROE） | 経常利益 ÷ 純資産 × 100 | 総合力（本来は当期純利益を使うが簡易的に経常利益で代用） |
| 流動比率 | 流動資産 ÷ 流動負債 × 100 | 短期安全性 |
| 売上高付加価値率 | 付加価値額 ÷ 売上高 × 100 | 生産性 |
| 労働生産性 | 付加価値額 ÷ 従業員数 | 生産性 |

診断は「業種平均の1.2倍以上＝良好」「0.8〜1.2倍＝平均的」「0.8倍未満＝要注意」を基本ルールとしています（流動比率のみ150%/100%を目安に別ロジック）。

## 比較データの出典

- 全産業の加重平均値（自己資本比率・売上高経常利益率・総資本回転率・ROE・付加価値比率）：中小企業庁「令和４年中小企業実態基本調査速報（令和３年度決算実績）」の公表値
- 業種別の売上高経常利益率・労働生産性：同調査で公表された「産業大分類別の１企業当たり売上高・経常利益・従業者数・付加価値額」から本ツールが算出した参考値
- 業種別の総資本回転率・ROE・売上高付加価値率：中小企業庁「令和元年中小企業実態基本調査」に基づく公開資料（[社長の教科書「経営指標とは」](https://suzuki-tax.net/shacho-kyokasho/management-indicators)）の業種別平均値
- 業種別の自己資本比率：同資料の「財務レバレッジ」（総資本÷自己資本）から 100 ÷ 財務レバレッジ で逆算した推計値
- 流動比率の目安（150%以上=良好、100%未満=要注意）：一般的な財務分析上のガイドライン

年度の異なるデータを組み合わせているため、あくまで目安・参考値です。正確な業種水準を確認したい場合は [e-Stat 中小企業実態基本調査](https://www.e-stat.go.jp/stat-search/files?page=1&toukei=00553010&tstat=000001019842) の産業中分類別データを直接参照してください。詳細な数値は `server/lib/benchmarks.js` にまとめています。

## API概要

すべて `/api` 配下。認証はセッションCookie方式。

- `POST /api/auth/register` `{email, password}`
- `POST /api/auth/login` `{email, password}`
- `POST /api/auth/logout`
- `GET /api/auth/me`
- `GET /api/companies/industries` 対応業種一覧
- `GET/POST /api/companies` クライアント企業の一覧・作成
- `GET/PUT/DELETE /api/companies/:id`
- `GET/POST /api/companies/:id/records` 決算/試算表データの一覧・追加
- `POST /api/companies/:id/records/import` `{csv: "..."}` CSV一括取込
- `DELETE /api/companies/:id/records/:recordId`
- `GET /api/companies/:id/diagnosis` 指標推移・診断結果
