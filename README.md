# 経営指標診断ツール（プロトタイプ）

決算データ（CSV）をアップロードすると、主要な経営指標を自動計算し、中小企業庁の統計データと比較して診断するWebツールです。ビルド不要の素のHTML/CSS/JSで動きます。

## 使い方

1. `index.html` をブラウザで開く（VSCodeなら拡張機能「Live Server」で開くと便利）
2. 業種を選択し、CSVをアップロード（または「サンプルデータを読み込む」で試す）
3. 指標の推移グラフと診断結果が表示される

## CSVフォーマット

1行目はヘッダー、1行=1年度分のデータ。金額の単位はすべて「円」。

| 列名 | 内容 |
|---|---|
| 年度 | 例: 2024年3月期 |
| 売上高 | 円 |
| 経常利益 | 円 |
| 総資産 | 円 |
| 純資産 | 円 |
| 流動資産 | 円 |
| 流動負債 | 円 |
| 従業員数 | 人 |
| 付加価値額 | 円（不明な場合は0でも可。労働生産性の診断のみスキップされる） |

サンプル: `data/sample.csv`

## 算出している指標

- 自己資本比率（安全性）
- 売上高経常利益率（収益性）
- 総資本回転率（効率性）
- 自己資本当期純利益率（簡易ROE）
- 流動比率（短期支払能力）
- 労働生産性（従業員1人当たり付加価値額）

## 比較データの出典

中小企業庁「令和４年中小企業実態基本調査速報（令和３年度決算実績）」
- 自己資本比率・売上高経常利益率（全産業平均）・総資本回転率・ROE・付加価値比率は公表値をそのまま使用
- 業種別の売上高経常利益率・労働生産性は、同調査で公表された「産業大分類別の１企業当たり売上高・経常利益・従業者数・付加価値額」から本ツールが算出した参考値（公式の業種別比率そのものではない）
- 流動比率の目安（150%以上=良好、100%未満=要注意）は一般的な財務分析上の目安
